BiofoamFirebreaks

An open framework for deploying, testing and scaling living firebreaks, part of a larger planetary impact initiative led by Symbiote #001.

Ember Lab: watch a foam band catch drifting embers

Drag Wind to push embers along, Foam depth to widen the barrier, and Ember rain to change how many fly. Try strong wind: embers can loft over a barrier, which is why a firebreak is one layer of protection and never a guarantee. This is a teaching toy built from simple rules, not data from real foam, and not a tool for deciding whether to evacuate or how to defend a home. Follow your local fire authority.

What this is

BiofoamFirebreaks is an open, modular framework for deploying, testing and scaling its firebreak mission in the real world. Think of the repository as a shared workshop: code, designs, evidence and community rules, all in one place anyone can inspect.

Nothing on this page claims the project is tested or proven. The README’s own checklist is still unticked, and this guide keeps it that way until you have evidence.

How to use this page: play with the Ember Lab to build intuition, open the project map to see what each folder is for, follow Get started, then use the repo checkup to tidy things before you share the project.

    Impact attribution and the ledger

    The README says impact is tracked by the Symbiote Ledger under Symbiote #001 and logged via IPFS, with optional chain notarization. Those integrations are future extensions. Here is the core idea, running only in your browser: a fingerprint is a short code made from a record. The same words always give the same code, and changing one letter changes the code completely, so anyone can later check that a record wasn’t altered without needing to see it.

    Nothing you type leaves this page. Any real notarization should be opt-in, explained in plain language, and never include personal data.
